Завдання 1: Фільтрація за віком та збереження в localStorage

Чому це важливо в React і як це працює

Дані у useState зберігаються лише до перезавантаження сторінки. Щоб фільтр користувача не зникав після оновлення вкладки, масив серіалізують у JSON-рядок (JSON.stringify) та записують у localStorage, а під час монтування компонента відновлюють у хуку useEffect через JSON.parse.

Покрокове виконання:

  1. Створіть файл UserFilter.jsx і винесіть на початок файлу масив initialUsers та константу STORAGE_KEY = 'task1_filteredUsers'.
  2. У компоненті UserFilter оголосіть два стани: users (початково initialUsers) та ageFilter (початково '').
  3. У хуку useEffect(() => { ... }, []) прочитайте запис за ключем STORAGE_KEY. Якщо збережений масив валідний і не порожній, передайте його у setUsers.
  4. Створіть обробник handleFilter: обчисліть minAge = ageFilter === '' ? 0 : Number(ageFilter), відфільтруйте initialUsers за умовою user.age >= minAge, оновіть стан setUsers(filtered) і збережіть масив у localStorage.
  5. У JSX додайте числовий інпут (type="number" min="0"), кнопку Фільтрувати в блоці .button-group та умовний вивід списку ul.user-list або повідомлення p.empty-message.
  6. Підключіть <UserFilter /> у LessonExamples в App.jsx.

Обов'язкові імена змінних, компонентів та ключів

• Компонент: UserFilter
• Ключ localStorage: 'task1_filteredUsers'
• Стани: users / setUsers, ageFilter / setAgeFilter
• Функція-обробник: handleFilter

💡 Підказки до складних місць:

  • Фільтруйте завжди початковий масив initialUsers, а не поточний стан users, щоб при зменшенні віку в інпуті поверталися раніше відфільтровані користувачі.
  • Огорніть JSON.parse(...) у блок try ... catch на випадок пошкоджених даних у сховищі.
  • Додатковий челендж (UserFilterImproved.jsx, компонент UserFilterImproved): зробіть реактивну версію без кнопки, де у localStorage (ключ 'task1_ageFilterValue') зберігається лише рядок ageFilter, а список обчислюється під час рендеру.
👁️ Очікуваний візуальний результат: секція .user-list-container із заголовком, числовим полем введення з підказкою «Введіть мінімальний вік», синьою кнопкою «Фільтрувати» та відфільтрованим списком карток, який не зникає після натискання F5.

Чому це важливо в React і як це працює

Компонент повинен керувати кількома режимами відображення одного набору даних без його втрати. Зберігаючи незмінний масив initialUsers поза компонентом, ми можемо в будь-який момент скинути сортування до початкового порядку елементів.

Покрокове виконання:

  1. Створіть файл Task2.jsx та оголосіть константу initialUsers перед компонентом Task2.
  2. Створіть стан const [users, setUsers] = useState(initialUsers).
  3. Реалізуйте три обробники подій:
    • handleSortAsc — сортує копію масиву від найменшого віку до найбільшого (a.age - b.age).
    • handleSortDesc — сортує копію масиву від найбільшого віку до найменшого (b.age - a.age).
    • handleReset — встановлює setUsers(initialUsers).
  4. Додайте у <div className="button-group"> три кнопки: «Сортувати за зростанням», «Сортувати за спаданням» і «Скинути сортування» (з класом className="btn-reset").

• Компонент: Task2
• Стан: users / setUsers
• Обробники: handleSortAsc, handleSortDesc, handleReset
• Клас кнопки скидання: btn-reset

Завдання 3: Оновлення віку (+1) зі збереженням та очищенням localStorage

Чому це важливо в React і як це працює

Поєднання лінивої ініціалізації (useState(() => ...)) та побічного ефекту (useEffect із залежністю [users]) дозволяє автоматично зберігати кожну зміну об'єктів масиву у браузерному сховищі без дублювання коду запису.

Покрокове виконання:

  1. Створіть файл Task3.jsx, оголосіть initialUsers та STORAGE_KEY = 'task3_users'.
  2. У компоненті Task3 ініціалізуйте стан users функцією, яка зчитує та парсить localStorage.getItem(STORAGE_KEY) (або повертає initialUsers, якщо запису немає).
  3. Додайте useEffect із залежністю [users], який записує актуальний масив у localStorage.
  4. Реалізуйте increaseAge(id), яка імутабельно збільшує поле age на 1 для обраного користувача.
  5. Реалізуйте handleReset(), яка повертає стан до initialUsers і викликає localStorage.removeItem(STORAGE_KEY).
  6. Додайте кнопку +1 у кожен <li> та червону кнопку Скинути (className="btn-reset") під списком. Підключіть <Task3 /> у LessonExamples.

Обов'язкові імена змінних, компонентів та ключів

• Компонент: Task3
• Ключ localStorage: 'task3_users'
• Функції: increaseAge(id), handleReset
• Кнопка скидання: className="btn-reset"

💡 Підказка:

Використовуйте унікальний ключ 'task3_users', щоб цей компонент не перезаписував дані інших завдань у межах одного localhost.

👁️ Очікуваний візуальний результат: список із кнопками +1 навпроти кожного користувача та червоною кнопкою «Скинути» знизу. Збільшений вік зберігається після перезавантаження сторінки, а «Скинути» повертає початкові числа (25, 30, 28).

Завдання 4: Базовий роутинг із двома сторінками

Чому це важливо в React і як це працює

У Single Page Application (SPA) зміна URL відбувається без перезавантаження HTML-документа з сервера. BrowserRouter відстежує адресу в браузері, NavLink змінює шлях і автоматично додає активному пункту меню клас active, а Routes підбирає відповідний Route.

Покрокове виконання:

  1. Створіть файл Users.jsx із компонентом Users, який відображає список користувачів (Олег, Анна, Іван) у контейнері <div className="user-list-container"> із заголовком <h2>Список користувачів</h2>.
  2. У файлі App.jsx імпортуйте компонент Users.
  3. Додайте в навігацію <nav><ul> посилання <li><NavLink to="/users">Користувачі</NavLink></li>.
  4. У контейнері <Routes> зареєструйте маршрут <Route path="/users" element={<Users />} />.

Обов'язкові імена файлів, компонентів та маршрутів

• Файл і компонент: Users.jsx → Users
• Маршрут: path="/users"
• Навігація: <NavLink to="/users">
• Заголовок сторінки: Список користувачів

💡 Підказка:

Не використовуйте звичайний тег <a href="/users"> — він спричинить повне перезавантаження сторінки та скине стан React. Завжди використовуйте <NavLink> або <Link>.

👁️ Очікуваний візуальний результат: миттєве перемикання між сторінками «Головна» (/) та «Користувачі» (/users) із підсвічуванням активної кнопки меню темно-синім кольором.

Чому це важливо в React і як це працює

Під час переходу на інший маршрут React демонтує (unmount) поточний компонент сторінки і видаляє його стан із пам'яті. Інтеграція з localStorage дозволяє сторінці /users/task5 відновлювати актуальний вік користувачів як при поверненні з іншої сторінки SPA, так і після перезавантаження браузера.

Покрокове виконання:

  1. Створіть файл UserList5.jsx із компонентом UserList5.
  2. Визначте масив initialUsers та константу STORAGE_KEY = 'task5_users'.
  3. Реалізуйте безпечне завантаження початкового стану users із localStorage, автоматичний запис змін через useEffect, функцію increaseAge(id) для кнопки +1 та функцію handleReset() для кнопки «Скинути».
  4. У App.jsx додайте посилання <NavLink to="/users/task5">Завдання 5</NavLink> та маршрут <Route path="/users/task5" element={<UserList5 />} />.

Обов'язкові імена файлів, компонентів та маршрутів

• Файл і компонент: UserList5.jsx → UserList5
• Ключ сховища: 'task5_users'
• Маршрут: path="/users/task5"
• Кнопки: +1 та button.btn-reset "Скинути"

💡 Підказка:

Перевірте коректність шляху: /users/task5 має бути зареєстрований як окремий <Route> у App.jsx поруч із /users.

Чому це важливо в React і як це працює

Замість збереження вже обрізаного масиву в localStorage правильніше зберігати сам критерій пошуку (filter), а список filteredUsers обчислювати на льоту під час рендеру. Тоді після перезавантаження сторінки користувач бачить і введений запит у полі пошуку, і відповідний результат.

Покрокове виконання:

  1. Створіть файл UserFilter.jsx із масивом initialUsers та ключем STORAGE_KEY = 'homework_nameFilter'.
  2. У компоненті UserFilter ініціалізуйте стан filter значенням із localStorage.getItem(STORAGE_KEY) || ''.
  3. Додайте useEffect із залежністю [filter], який зберігає поточний рядок пошуку в localStorage.
  4. Обчисліть filteredUsers через .filter() без урахування регістру та початкових/кінцевих пробілів (.trim().toLowerCase()).
  5. Створіть функцію handleReset, яка очищає стан setFilter('') та видаляє ключ через localStorage.removeItem(STORAGE_KEY).
  6. Оформіть контейнер як <div className="user-list-container user-filter">, додайте текстовий інпут (placeholder="Пошук за ім'ям"), кнопку «Скинути фільтр» та виведіть список або повідомлення <p className="empty-message">Користувачів з ім'ям «{filter}» не знайдено</p>.
  7. Імпортуйте компонент у App.jsx як HomeworkUserFilter та зареєструйте маршрут /homework/users/filter.

Обов'язкові імена файлів, компонентів та ключів

• Файл: UserFilter.jsx
• Імпорт у App.jsx: HomeworkUserFilter
• Ключ сховища: 'homework_nameFilter'
• Маршрут: path="/homework/users/filter"
